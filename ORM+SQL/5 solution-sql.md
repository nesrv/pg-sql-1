
# Решения 

## Соединение таблиц

1. Соедините две таблицы `Orders` и `Customers` с помощью команды `SELECT` (декартово произведение)
2. Соедините две таблицы `customers` и `orders` с помощью обычного `JOIN`
3. Соедините две таблицы `customers` и `orders` с помощью  `LEFT JOIN`
4. Выведите покупателей, которые ничего не купили
5. Выведите `ID` товаров, которые не были проданы
6. Выведите название непроданных товаров
7. Выведите все заказы на товары, производителем которых является `Apple`.
8. Выведите для каждого покупателя количество заказов, которые он сделал
9. Вывести товары с общей суммой сделанных заказов
10. Найти всех клиентов, которые могут позволить себе покупку `iPhone X` (учитывая сумму на их счету). 
Вывести их имена и сумму на счету.
11. Вычислить среднюю цену всех товаров со скидкой и без скидки отдельно. Вывести результат в виде двух столбцов: `WithDiscount` и `WithoutDiscount`.


```sql
SELECT *
FROM Orders
JOIN Products ON
productid = Products.id;

SELECT productname
FROM orders
RIGHT JOIN customers ON
customers.id = orders.customerid
RIGHT JOIN products ON
products.id = productid
WHERE productid IS NULL;


SELECT c.FirstName, c.LastName, c.AccountSum
FROM Customers c
JOIN Products p ON p.ProductName = 'iPhone X'
WHERE c.AccountSum >= p.Price;



SELECT 
    (SELECT AVG(Price) FROM Products WHERE IsDiscounted = true) AS WithDiscount,
    (SELECT AVG(Price) FROM Products WHERE IsDiscounted = false) AS WithoutDiscount;

```
