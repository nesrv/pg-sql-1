# Полиморфные связи

## Исходные данные

### Описание: 


Система учета актеров и фильмов:

* где один актер может сниматься в нескольких фильмах, 
* и один фильм может иметь нескольких актеров.


```sql

CREATE TABLE Actor (
    ActorID INT PRIMARY KEY,
    Name VARCHAR(100)
);

CREATE TABLE Movie (
    MovieID INT PRIMARY KEY,
    Title VARCHAR(100)
);

CREATE TABLE ActorMovie (
    ActorID INT,
    MovieID INT,
    PRIMARY KEY (ActorID, MovieID),
    FOREIGN KEY (ActorID) REFERENCES Actor(ActorID),
    FOREIGN KEY (MovieID) REFERENCES Movie(MovieID)
);
```

# Задания к коду базы данных "Актеры и фильмы"

## Базовые задания

1. **Вставка данных**
   - Добавьте 5 актеров в таблицу `Actor`
   - Добавьте 5 фильмов в таблицу `Movie`
   - Создайте связи между актерами и фильмами (каждый актер должен участвовать минимум в 2 фильмах, каждый фильм должен иметь минимум 3 актера)

2. **Простые запросы**
   - Напишите запрос, который выводит всех актеров
   - Напишите запрос, который выводит все фильмы
   - Напишите запрос, который показывает, сколько фильмов снял каждый актер

3. **Запросы с соединениями**
   - Выведите список всех фильмов с участием конкретного актера
   - Выведите список всех актеров, снимавшихся в конкретном фильме
   - Найдите все фильмы, в которых снимались более 4 актеров

## Продвинутые задания

4. **Аналитические запросы**
   - Найдите актера, снявшегося в наибольшем количестве фильмов
   - Найдите фильм с наибольшим количеством актеров
   - Выведите статистику: среднее количество актеров на фильм

5. **Обновление данных**
   - Добавьте нового актера и свяжите его с 3 существующими фильмами
   - Удалите один фильм и все связанные с ним записи (используйте каскадное удаление или дополнительные запросы)
   - Измените название одного фильма

6. **Оптимизация**
   - Добавьте индекс для ускорения поиска актеров по имени
   - Напишите запрос, который показывает, какие актеры снимались вместе в одних и тех же фильмах
   - Создайте представление (VIEW), которое показывает полную информацию о фильмах и их актерах

## Практические задания

7. **Реальные сценарии**
   - Создайте запрос для поиска всех фильмов, где снимались два конкретных актера вместе
   - Напишите запрос, который находит актеров, которые не снимались ни в одном фильме
   - Реализуйте поиск фильмов по части названия и актерам, которые в них снимались

8. **Дополнительные задачи**
   - Добавьте в таблицу `ActorMovie` поле `Role` (роль актера в фильме) и обновите данные
   - Напишите запрос, который показывает все роли конкретного актера
   - Найдите все фильмы, где актер играл главную роль (предположим, главная роль помечается как "Lead")
