# Задание

Удалить из таблицы attempt все попытки, выполненные раньше 1 мая 2020 года. 
Также удалить и все соответствующие этим попыткам вопросы из таблицы testing, которая создавалась следующим запросом:

```sql
CREATE TABLE testing (
    testing_id INT PRIMARY KEY GENERATED ALWAYS AS IDENTITY,
    attempt_id INT,
    question_id INT,
    answer_id INT,
    FOREIGN KEY (attempt_id) REFERENCES attempt (attempt_id) ON DELETE CASCADE
);


```

```sql

--solution-1

DELETE
FROM attempt
WHERE date_attempt < '2020-05-01';

--solution-2-without-cascading

DELETE
FROM attempt a
    USING testing t
WHERE a.attempt_id = t.attempt_id
  AND a.date_attempt < '2020-05-01';
```
