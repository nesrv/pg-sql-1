
# Задание


Провести аналитику по трем ценовым категориям (до 600 руб, от 600 руб до 700 руб, свыше 700 руб) и вывести среднюю цену  книги, общую стоимость остатков книг  в этой ценовой позиции и количество позиций. 

Среднюю цену и стоимость округлить до двух знаков после запятой. 

Информацию отсортировать по возрастанию нижней границы ценовой категории.


Результат:


| beg_range | end_range | Средняя_цена | Стоимость | Количество |
|-----------|-----------|--------------|-----------|------------|
| 0         | 600       | 493.67       | 12107.50  | 3          |
| 600       | 700       | 660.50       | 11762.97  | 2          |
| 700       | 10000     | 799.01       | 2397.03   | 1          |



Для реализации этого запроса создадим вспомогательную таблицу stat, 
в которой будут храниться ценовые категории 
(первая ценовая категория - цены  больше или равны 0 и меньше 600, вторая - больше или равны 600 и меньше 700 и т.д.):



```sql
CREATE TABLE stat
(
    beg_range int,
    end_range int
);

INSERT INTO stat(beg_range, end_range)
VALUES (0, 600),
       (600, 700),
       (700, 10000);


--solution-1

SELECT beg_range,
       end_range,
       ROUND(AVG(price), 2)          AS "Средняя_цена",
       ROUND(SUM(amount * price), 2) AS "Стоимость",
       COUNT(amount)                 AS "Количество"
FROM stat
         JOIN book ON price < end_range AND price > beg_range
GROUP BY 1, 2
ORDER BY 1;


--solution-2

SELECT beg_range,
       end_range,
       AVG(price)          AS "Средняя_цена",
       SUM(amount * price) AS "Стоимость",
       SUM(amount)         AS "Количество"
FROM stat,
     book
WHERE price BETWEEN beg_range AND end_range
GROUP BY 1, 2
ORDER BY 1;

```
