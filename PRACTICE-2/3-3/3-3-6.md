# Задание


Посчитать, сколько дополнительных баллов получит каждый абитуриент. 
Столбец с дополнительными баллами назвать Бонус. 
Информацию вывести в отсортированном по фамилиям виде.


# Результат


| name_enrollee   | Бонус |
|-----------------|-------|
| Абрамова Катя   | 0     |
| Баранов Павел   | 6     |
| Попов Илья      | 8     |
| Семенов Иван    | 5     |
| Степанова Дарья | 0     |
| Яковлева Галина | 1     |



```sql
--solution-1


SELECT name_enrollee, SUM(CASE WHEN bonus > 0 THEN bonus ELSE 0 END) AS "Бонус"
FROM enrollee
         NATURAL LEFT JOIN enrollee_achievement
         NATURAL LEFT JOIN achievement
GROUP BY 1
ORDER BY 1;


--solution-2


SELECT name_enrollee, COALESCE(SUM(bonus), 0) AS "Бонус"
FROM enrollee
         NATURAL LEFT JOIN enrollee_achievement
         NATURAL LEFT JOIN achievement
GROUP BY 1
ORDER BY 1;


--solution-3




```
