# Задание

Составить рейтинг книг в зависимости от того, какая книга принесет больше всего выручки (в процентах), при условии продажи всех книг. 

Рейтинг отсортировать по убыванию выручки. 

Выручка в процентах вычисляется как стоимость всех экземпляров книги деленное на суммарную стоимость всех экземпляров книг на складе и умноженное на 100, полученный результат округлить до двух знаков после запятой.

Результат


| author           | title                 | price  | amount | income_percent |
|------------------|-----------------------|--------|--------|----------------|
| Есенин С.А.      | Стихотворения и поэмы | 650.00 | 15     | 33.83          |
| Достоевский Ф.М. | Игрок                 | 480.50 | 10     | 16.67          |
| Достоевский Ф.М. | Идиот                 | 460.00 | 10     | 15.96          |
| Есенин С.А.      | Черный человек        | 670.99 | 5      | 11.64          |
| Булгаков М.А.    | Белая гвардия         | 540.50 | 5      | 9.38           |

| Достоевский Ф.М. | Братья Карамазовы     | 799.01 | 2      | 5.54           |


```sql

WITH TEMP AS
(
SELECT sum(price*amount) AS total FROM books) 
SELECT 
	author, 
	title, 
	price, 
	amount, 
	round(price * amount / (SELECT total FROM TEMP) * 100,2) AS income_percent
FROM books
ORDER BY income_percent DESC;



WITH total_income AS (
    SELECT SUM(price * amount) as total 
    FROM books
)
SELECT 
    b.author,
    b.title, 
    b.price, 
    b.amount,
    ROUND((b.price * b.amount) / t.total * 100, 2) AS income_percent
FROM books b
CROSS JOIN total_income t
ORDER BY income_percent DESC;


SELECT 
	author, 
	title, 
	price, 
	amount, 
	round(price * amount / (SELECT sum(price*amount) AS total FROM books) * 100,2) AS income_percent
FROM books
ORDER BY income_percent DESC;






SELECT author,
	title, 
	price, 
	amount,
	ROUND( (price * amount) / SUM(price * amount) OVER() * 100, 2) AS income_percent
FROM books
ORDER BY
    income_percent DESC;


-- Что делает OVER():
-- OVER() определяет окно, по которому будет производиться агрегация
-- В данном случае пустые скобки () означают, что окно охватывает ВСЕ строки результата
-- SUM() вычисляет общую сумму для всех книг
```
