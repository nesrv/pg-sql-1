# Задание

Создать новую таблицу store, в которую занести данные из таблиц book и supply, при условии,

- что количество книг будет больше среднего количества книг по двум таблицам;

- если книга есть в обеих таблицах, то стоимость выбрать большую из двух.

Отсортировать данные из таблицы их по имени автора в алфавитном порядке и по убыванию цены.

Расшифровка фразы: "среднее количество книг по двум таблицам" - это сумма всех amount в обеих таблицах делённая на количество позиций в обеих таблицах.

Одинаковые книги не нужно перед этим объединять.

Вывести данные из полученной таблицы.

Результат:

SELECT title, price, amount

    SELECT title, price, amount

GROUP BY title, author
HAVING sum(t1.amount) > (SELECT AVG(amount) FROM t1)
