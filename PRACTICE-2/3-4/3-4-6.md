## Нумерация строк

Номер строки в таблице или запросе в некоторых версиях SQL можно получить с помощью оконной функции  row_number().  

Пример

Пронумеруем записи в таблице applicant_order.

Запрос:

```sql
SELECT *, ROW_NUMBER() OVER (ORDER BY NULL) AS str_num
FROM applicant_order;
```

Результат:


| program_id | enrollee_id | itog | str_num |
|------------|-------------|------|---------|
| 1          | 3           | 235  | 1       |
| 1          | 2           | 226  | 2       |
| 1          | 1           | 219  | 3       |
| 2          | 6           | 276  | 4       |
| 2          | 3           | 235  | 5       |
| 2          | 2           | 226  | 6       |
| 3          | 6           | 270  | 7       |
| 3          | 4           | 239  | 8       |
| 3          | 5           | 200  | 9       |
| 4          | 6           | 270  | 10      |
| 4          | 3           | 247  | 11      |
| 4          | 5           | 200  | 12      |


Объяснение:

В PostgreSQL используется функция ROW_NUMBER() с предложением OVER

ORDER BY NULL используется для генерации последовательного номера без сортировки

a.* означает выбор всех столбцов из таблицы applicant_order

Пример

Создадим нумерацию, которая начинается заново для каждой образовательной программы. 

```sql
SELECT *, ROW_NUMBER() OVER (PARTITION BY program_id ORDER BY program_id) AS str_num
FROM applicant_order;
```

Объяснение:

```sql
ROW_NUMBER() OVER 
--используется для генерации последовательного номера

PARTITION BY program_id 
--разбивает данные на группы по program_id

ORDER BY program_id 
          
--определяет порядок нумерации внутри каждой группы
```

Альтернативные варианты:
```sql
-- С сортировкой по другому столбцу внутри групп
SELECT 
    *,
    ROW_NUMBER() OVER (PARTITION BY program_id ORDER BY created_at) AS str_num
FROM 
    applicant_order;

-- С дополнительными колонками для отладки
SELECT 
    *,
    program_id AS current_program,
    ROW_NUMBER() OVER (PARTITION BY program_id ORDER BY created_at) AS str_num
FROM 
    applicant_order;
```



```sql
--solution-1

UPDATE applicant_order a
SET str_id = sub.row_num
FROM (SELECT program_id,
             enrollee_id,
             ROW_NUMBER() OVER (PARTITION BY program_id ORDER BY program_id DESC, enrollee_id) AS row_num
      FROM applicant_order) sub
WHERE a.program_id = sub.program_id
  AND a.enrollee_id = sub.enrollee_id;
```
