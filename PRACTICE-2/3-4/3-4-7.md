# Задание


Создать таблицу student,  в которую включить абитуриентов, которые могут быть 
рекомендованы к зачислению в соответствии с планом набора.

Информацию отсортировать сначала в алфавитном порядке по названию программ, а потом по убыванию итогового балла.


Результат:


| name_program                        | name_enrollee   | itog |
|-------------------------------------|-----------------|------|
| Математика и компьютерные науки     | Степанова Дарья | 276  |
| Мехатроника и робототехника         | Степанова Дарья | 270  |
| Мехатроника и робототехника         | Семенов Иван    | 247  |
| Мехатроника и робототехника         | Попов Илья      | 200  |
| Прикладная математика и информатика | Семенов Иван    | 235  |
| Прикладная математика и информатика | Абрамова Катя   | 226  |
| Прикладная механика                 | Степанова Дарья | 270  |
| Прикладная механика                 | Яковлева Галина | 239  |


целесообразно изменить сортировку в таблице applicant_order

```sql
UPDATE applicant_order a
SET str_id = sub.row_num
FROM (SELECT program_id,
             enrollee_id,
             ROW_NUMBER() OVER (PARTITION BY program_id ORDER BY itog DESC, program_id DESC, enrollee_id) AS row_num
      FROM applicant_order) sub
WHERE a.program_id = sub.program_id
  AND a.enrollee_id = sub.enrollee_id;

```


```sql

--prepare-1

SELECT name_program, name_enrollee, itog, str_id, plan
FROM program
         NATURAL JOIN applicant_order
         NATURAL JOIN enrollee
ORDER BY 3 DESC;


--prepare-2

SELECT name_program, name_enrollee, itog, str_id, plan
FROM program
         NATURAL JOIN applicant_order
         NATURAL JOIN enrollee
WHERE str_id <= plan
ORDER BY 1, 3 DESC;


--solution-2


CREATE TABLE students AS
SELECT name_program,
       name_enrollee,
       itog
FROM program
         NATURAL JOIN applicant_order
         NATURAL JOIN enrollee
WHERE str_id <= plan
ORDER BY name_program,
         itog DESC;

```
