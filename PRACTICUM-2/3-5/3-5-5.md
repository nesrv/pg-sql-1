# Табличные выражения, оператор WITH

# Пример


Для каждого шага вывести процент правильных решений.

Информацию упорядочить по возрастанию процента верных решений. 

Столбцы результата назвать Шаг и Успешность, процент успешных решений округлить до целого.

Важно. Только для этого задания для одного из шагов установлено, что все ответы пользователей - неверные.


1) Создадим запрос, который для каждого шага вычисляет количество правильных и неправильных ответов, данных пользователями.
2) Создадим запрос с табличными выражениями, который вычисляет процент верных решений. 

```sql
SELECT step_name, COUNT(*)
FROM step
         NATURAL JOIN step_student
WHERE result = 'correct'
GROUP BY step_name;

-- или

SELECT step_name,
       SUM(CASE
               WHEN result = 'correct' THEN 1
               ELSE 0 END) AS correct,
       SUM(CASE
               WHEN result = 'wrong' THEN 1
               ELSE 0 END) AS wrong,
       COUNT(*)            AS total
FROM step
         NATURAL JOIN step_student
GROUP BY 1;


-- обернем его в табличное выражение

WITH get_count_answer (step_name, count_correct, count_wrong, total_count) AS
         (SELECT step_name,
                 SUM(CASE
                         WHEN result = 'correct' THEN 1
                         ELSE 0 END) AS correct,
                 SUM(CASE
                         WHEN result = 'wrong' THEN 1
                         ELSE 0 END) AS wrong,
                 COUNT(*)            AS total
          FROM step
                   NATURAL JOIN step_student
          GROUP BY 1)
SELECT *
FROM get_count_answer;


-- далее


WITH get_count_answer (Шаг, count_correct, count_wrong, total) AS
         (SELECT step_name,
                 SUM(CASE
                         WHEN result = 'correct' THEN 1::NUMERIC
                         ELSE 0 END),
                 SUM(CASE
                         WHEN result = 'wrong' THEN 1::NUMERIC
                         ELSE 0 END),
                 COUNT(*)
          FROM step
                   NATURAL JOIN step_student
          GROUP BY 1)
SELECT Шаг, ROUND(count_correct / total, 2) * 100 AS Успешность
FROM get_count_answer
ORDER BY 2;


```

# Задание

Исправить запрос примера так: для шагов, которые  не имеют неверных ответов,
указать 100 как процент успешных попыток, если же шаг не имеет верных ответов, указать 0. 
Информацию отсортировать сначала по возрастанию успешности, а затем по названию шага в алфавитном порядке.


Результат


| Шаг                                                                      | Успешность |
|--------------------------------------------------------------------------|------------|
| Задание. Работа с архивной таблицей, оператор UNION, часть 1             | 0          |
| Выборка данных, оператор LIKE                                            | 19         |
| Вложенные запросы в операторах соединения                                | 32         |
                     ....
| Выборка отдельных столбцов и присвоение им новых имен                    | 84         |
| Выборка всех данных из таблицы                                           | 87         |
| Задание. Работа с архивной таблицей, оператор UNION, часть 2             | 100        |
| Построение логической схемы базы данных                                  | 100        |



```sql
SELECT step_name                                                                   AS "Шаг",
       ROUND(100 * SUM(CASE WHEN result = 'correct' THEN 1 ELSE 0 END) / COUNT(*)) AS "Успешность"
FROM step
         NATURAL JOIN step_student
GROUP BY step_id,
         step_name
ORDER BY "Успешность",
         "Шаг";

```
