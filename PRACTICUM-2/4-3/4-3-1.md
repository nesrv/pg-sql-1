# Задание

Вывести авторов и названия книг и их цену в двух столбцах - рубли и копейки. Информацию отсортировать по убыванию копеек.

Результат

| author           | title                 | Рубли | Копейки |
| ---------------- | --------------------- | ----- | ------- |
| Булгаков М.А.    | Мастер и Маргарита    | 670   | 99      |
| Есенин С.А.      | Черный человек        | 670   | 99      |
| Булгаков М.А.    | Белая гвардия         | 540   | 50      |
| Достоевский Ф.М. | Игрок                 | 480   | 50      |
| Достоевский Ф.М. | Братья Карамазовы     | 799   | 1       |
| Достоевский Ф.М. | Идиот                 | 460   | 0       |
| Есенин С.А.      | Стихотворения и поэмы | 650   | 0       |


```sql


SELECT author, title, amount, TRUNC(price) AS Рубли,  MOD(price * 100, 100) AS Копейки
FROM books
ORDER BY 5 desc




SELECT 
author,
title, 
floor(price) as Рубли, 
round((price-floor(price))*100) as Копейки
FROM books
ORDER BY  Копейки desc;
	



SELECT author, title, ROUND(price - price % 1, 0) AS Рубли, ROUND(price % 1 * 100) AS Копейки
FROM book
ORDER BY 4 DESC




--mysql
SELECT author, title,
 FLOOR(price) AS Рубли,
  CAST(MOD(price * 100, 100) AS UNSIGNED INTEGER) as Копейки
FROM book
ORDER BY 4 desc



```
