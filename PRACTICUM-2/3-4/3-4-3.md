# Задание

Повысить итоговые баллы абитуриентов в таблице applicant на значения дополнительных баллов 
(использовать запрос из предыдущего урока).

![img_2.png](img_2.png)



Результат


| program_id | enrollee_id | itog |
|------------|-------------|------|
| 1          | 3           | 235  |
| 1          | 2           | 226  |
| 1          | 1           | 219  |
| 2          | 6           | 276  |
| 2          | 3           | 235  |
| 2          | 2           | 226  |
| 3          | 6           | 270  |
| 3          | 4           | 239  |
| 3          | 5           | 200  |
| 4          | 6           | 270  |
| 4          | 3           | 247  |


```sql
--solution-1


WITH sub_query AS (SELECT enrollee_id, SUM(bonus) AS dop
                   FROM achievement
                            NATURAL JOIN enrollee_achievement
                   GROUP BY 1)
UPDATE applicant
SET itog=itog + sub_query.dop
FROM sub_query
WHERE applicant.enrollee_id = sub_query.enrollee_id;


--solution-2

WITH sub_query AS (SELECT ea.enrollee_id,
                          SUM(a.bonus) AS dop
                   FROM achievement a
                            JOIN
                        enrollee_achievement ea ON a.achievement_id = ea.achievement_id
                   GROUP BY ea.enrollee_id)
UPDATE applicant a
SET itog = a.itog + COALESCE(sq.dop, 0)
FROM sub_query sq
WHERE a.enrollee_id = sq.enrollee_id;

```
